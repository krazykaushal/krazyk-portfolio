Body starts here, in Markdown.

Because these are `.mdx` files and not `.md`, you can also import components
and drop them inline — an Astro component for static markup, or a React island
with a `client:*` directive if it needs to be interactive:

{/* import Chart from '@/components/blog/Chart.tsx'; */}
{/* <Chart client:visible /> */}

Note that this comment syntax is a JSX expression, not an HTML comment, so it
does not ship to the browser. In MDX, `<` and `{` are meaningful — wrap them in
backticks when you mean them literally.
