This snippet is useful when you have fresh install of docker on a machine, and you want to run docker commands without using `sudo` (i.e. Manage Docker as non-root user) as by default only the Root user can run docker commands.

1. Add user `$USER` (e.g. ubuntu) to the docker group

```bash
sudo usermod -aG docker $USER
```

2. If you restart the terminal or SSH session, you can see the effect that now you can use docker without sudo, but to take them effect immediately you must run the following command.

```bash
newgrp docker
```

3. Verify the Installation

```bash
docker --version
docker compose version
```

The above should run without throwing any error.
